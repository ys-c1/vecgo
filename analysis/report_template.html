覆盖率采样的停点分析：样本数该在何处停

同一几何模型（旋转 30° 的 10×10 方形）在两个画幅上的蒙特卡洛覆盖率采样实验

数据来源：cmd/exp，每点 40 次独立重复，计时取 15 次中位数 · 随机源为固定种子 splitmix64，可复现

结论先行

1. 生产代码里没有"偷偷加样本"的状态。当前 raster.Image.Fill 是确定性网格超采样，采样数只来自配置项 Supersample（1–8），渲染函数内不存在累加/持久状态。漂移检查（下图④）证实：固定 s=2 连跑 11 次，耗时恒定在 ~2.7 ms；只有当外部把 s 从 2 逐次抬到 8 时，耗时才随 s² 从 2.6 ms 涨到 41.8 ms。客户看到的"一次比一次慢"对应的是调用方传入的采样参数在逐次变大，不是渲染器内部行为。

2. 停点只由边缘几何决定，与画幅无关。覆盖率方差 v(n)=C/n，其中 C = mean p(1−p)，只含边缘像素的覆盖率分布。两个画幅的 C 几乎相等（0.1259 vs 0.1273，差 1.1%），按"边际收益跌破首样本 1%"反算的停点 n* = 1/√ε = 10 对两个画幅是同一个数；离散网格上两者都在 n=12 首次实测越线。

3. 越过停点的代价随画幅放大。每边缘像素的采样成本与画幅无关，但边缘像素数随线性尺寸增长（245 → 975，约 4 倍）。同样把样本从 10 加到 256：64 画幅多花 0.87 ms，256 画幅多花 3.61 ms——停点取错时，画幅越大绝对损耗越大（耗时曲线③）。

方法与口径

停点的反算

单个边缘像素覆盖率估计：p̂ = (1/n)·Σ Xᵢ，Xᵢ ∈ {0,1}，故 Var(p̂) = p(1−p)/n

边缘像素平均方差：v(n) = C/n，C = mean[p(1−p)]，只由边缘几何决定

每样本边际收益（连续近似）：|dv/dn| = C/n²；首样本量级 = C

停点规则 C/n² ≤ ε·C ⇒ n* = 1/√ε，C 被约掉——画幅项不出现

取 ε = 0.01 得 n* = 10。离散网格上用相邻点的实测差商判断，两画幅均在 n=12 首次满足（n=10 的差商含 n=8→10 的区间平均，略高于阈值，属网格粒度效应）。

为什么 C 与画幅无关

同一世界坐标的模型映射到不同画幅时，边缘像素的覆盖率 p 是"边缘穿过像素的几何比例"。只要边缘相对像素网格的朝向分布不变（本实验为同模型、像素宽高比一致），p 的分布就不变，mean p(1−p) 随之不变；画幅改变的只是边缘像素的数量（随线性尺寸增长），不是单个像素的方差。实测 C₆₄ = 0.12592、C₂₅₆ = 0.12729，相对差 1.1%。

实验边界

  • 生产 Fill 是规则网格超采样（无随机性），方差分析在同口径的逐像素独立蒙特卡洛采样器上进行；两者单样本成本结构相同（每样本一次 geom.Inside），停点结论可直接迁移到超采样阶数的选择。
  • 真实覆盖率基准用 65536 样本估计；经验 MSE 与理论 C/n 的最大相对偏差 <5%。
  • 计时在同一机器单次会话内完成，已做预热并取中位数；绝对毫秒数随机器变化，但线性关系与画幅间倍数稳定。
