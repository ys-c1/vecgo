# 细长三角形重心插值实验（可复现说明）

## 复现方式

```bash
cd analysis/stripe
python3 -I experiment.py
```

仅依赖系统包 numpy 与 Pillow（`-I` 隔离模式下可用；不读取任何外部数据文件）。
随机种子固定为 20261126，结果逐次可复现。

## 文件清单

| 文件 | 内容 |
|---|---|
| `experiment.py` | 全部实验：几何量、有限差分雅可比、扰动误差、连通段计数、阈值扫描、出图 |
| `table.md` / `table.csv` | 三组三角形的条件数、误差界、剔除前后条纹数（主表） |
| `sweep.csv` | 面积阈值扫描（含题目要求的阈值两侧各一次运行） |
| `before_cull.png` | 剔除前场景（float32 计算 + 三顶点各 1px 随机扰动，伪彩编码） |
| `after_cull.png` | 剔除后场景（A < τ 的 G3 仅画轮廓，不参与插值） |
| `apex_compare.png` | G3 钝角顶点放大：上=精确几何，下=扰动渲染（条带碎裂对照） |
| `apex_zoom.png` | G3 钝角顶点扰动渲染单图放大 |

配套证明见 `doc/stripe.md`（条件数推导、误差界、阈值推导、结果对照）。

## 关键口径

- 条件数：κ = Lmax / A，单位 px⁻¹（题目指定，Lmax 为最大边长，A 为面积）。
- 扰动预算：δ = 1 px，三顶点独立、模长恰为 δ 的随机位移；扰动渲染全程 float32。
- 量化：每通道 N = 8 色阶，像素码 = (q0, q1, q2) 的整数编码。
- 条纹数：三角形包围盒内同码像素的 **4-连通分量数**（并查集实现）；
  CSV 另附扫描行 run 口径对照。理想渲染下每码对应一个凸的单连通带。
- 剔除阈值：τ = (N−1)·δ·Lmax = 7·1·480 = 3360 px²，
  对应 κcrit = 1/[(N−1)δ] = 0.142857 px⁻¹，剔除后误差 ≤ 半个色阶 1/14。
