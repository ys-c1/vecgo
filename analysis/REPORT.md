# 降采样核的频域分析：盒式、高斯与混叠—锐度不可兼得

## 0. 问题与结论先行

`raster/raster.go` 的超采样降采样（`Fill` 中 `255*hit/den`）在频域上等价于一个
**s×s 抽头的盒式核**（box filter，面积平均）。盒式核在边缘产生摩尔纹，换成高斯核后
摩尔纹减轻但画面变糊。本报告用频域传递函数和能量积分严格说明三件事：

1. 两种降采样的等效传递函数不同，混叠能量可以写成核频谱在阻带上的积分；
2. 在固定核宽（等效半径）下，混叠能量存在由不确定性原理给出的下界，
   **“无摩尔纹”和“保持锐度”是同一频谱形状上两个相反方向的要求，不存在同时满足的核**；
3. 数值实验在 s = 2 / 4 / 8 三档缩放比下，并排放出混叠能量与梯度锐度，
   并以 Lanczos-3 作为外部基准说明工程出路。

**一句话结论**：摩尔纹来自核在输出 Nyquist 之外残留的频谱能量，压它必须加宽核；
而加宽核必然压低通带传递函数、损失梯度能量。高斯核的优势是没有 sinc 旁瓣，
但在与盒式核**相同等效半径**的公平比较下，两者混叠能量处于同一量级
（白噪声基准 Q：盒 0.226、高斯 0.214），高斯换来的“干净”主要来自更平滑的旁瓣包络，
而不是更小的总泄漏。真正突破这个权衡需要带负瓣的核（Lanczos），见第 6 节。

## 1. 符号与降采样模型

输入序列 `x[n]`，采样间距归一化为 1，频率 ν 单位为“周/输入样本”，输入 Nyquist 为 1/2。
降采样因子 s，输出采样率为 1/s，**输出 Nyquist（新基带边界）**

```
f_c = 1/(2s).
```

标准的“预滤波 + 抽取”降采样器：

```
v[n] = (h * x)[n] = Σ_k h[k] x[n−k],      y[m] = v[s m].
```

`raster.Fill` 里对每个输出像素取 s² 个超采样点的平均，一维化后就是
`h_box[k] = 1/s, k = 0,…,s−1` 的盒式卷积再抽取。

### 1.1 混叠的频域机制

`y[m] = v[s m]` 的离散时间傅里叶变换是经典的混叠求和式：

```
Y(f) = (1/s) Σ_{k=0}^{s−1} V((f − k)/s)
     = (1/s) Σ_{k=0}^{s−1} H((f − k)/s) · X((f − k)/s),     f ∈ [−1/2, 1/2].
```

k = 0 项是基带分量；k ≥ 1 项是从高频段 `|ν| ≥ f_c` 折叠回新基带的**混叠分量**。
摩尔纹就是这些折叠项与基带在空间上拍频形成的可见低频纹路（见 `fig4_zoneplate.png`）。

## 2. 两种核的等效传递函数（按核的傅里叶变换写出）

### 2.1 盒式核

连续域上宽度为 s、单位面积的盒函数
`h_box(t) = (1/s)·1[−s/2, s/2](t)`，其傅里叶变换为

```
H_box(ν) = ∫ h_box(t) e^{−j 2πνt} dt = sinc(π s ν),     sinc(u) ≜ sin(u)/u.
```

实际离散核（s 个抽头）的 DTFT 是 Dirichlet 核，与连续 sinc 的关系为

```
H_box^d(ν) = (1/s) Σ_{n=0}^{s−1} e^{−j 2πν (n − (s−1)/2)}
           = e^{jπν(s−1)} · sin(π s ν) / (s sin(π ν)).
```

图 `fig1_transfer.png` 同时画出连续 FT（实线）与离散 DTFT（点线），二者在
ν ≤ f_c 内几乎重合，差异只在高频。

### 2.2 高斯核

`h_gauss(t) = (1/(σ√(2π))) exp(−t²/(2σ²))`，傅里叶变换仍是高斯：

```
H_gauss(ν) = exp(−2 π² σ² ν²).
```

它**没有零点、没有旁瓣**，按 `exp(−const·ν²)` 单调衰减；而盒式核的 sinc 有
无限多个旁瓣，包络只按 1/ν 衰减。这就是“盒式有明显摩尔纹、高斯更干净”的
频域根源（图 1 右的 dB 图最直观：盒式在第一零点后旁瓣在 −15 dB 上下振荡，
高斯则平滑地一路跌到 −50 dB 以下）。

### 2.3 公平比较：统一到同一等效半径

直接拿“s 抽头盒式”和“某个 σ 的高斯”比是不公平的，必须先配平核宽。
本报告用**概率二阶矩等效半径**作为统一口径（对非负核就是空间方差）：

```
r_p² = Σ_n n² h[n]          (h 归一化到 Σh = 1).
```

- s 抽头离散盒式核：`r_p² = (s² − 1)/12`；
- 令高斯 `σ² = (s² − 1)/12`，两者概率二阶矩严格相等。

例如 s = 4：盒式 `r_p² = 15/12 = 1.25`，高斯 `σ = √1.25 = 1.1180`。
代码中 `gaussian_kernel(s)` 即按此配平（`kernels.py`）。报告同时记录能量半径
`r_E² = Σ n² h[n]² / Σ h[n]²`，它对带负瓣的 Lanczos 核也有定义。

## 3. 混叠能量写成核频谱的积分

设输入功率谱密度为 `S_x(ν)`（归一化使 `∫_{−1/2}^{1/2} S_x(ν) dν = E[x²]`）。
预滤波后频谱为 `|H(ν)|² S_x(ν)`。折叠到输出基带后，**每个输出样本的均方能量**为

```
E[y²] = ∫_{−1/2}^{1/2} |H(ν)|² S_x(ν) dν.
```

以输出 Nyquist `f_c = 1/(2s)` 为界拆成基带能量与混叠能量：

```
E_b = ∫_{|ν| < f_c}  |H(ν)|² S_x(ν) dν   （基带，保留的细节）
E_a = ∫_{|ν| ≥ f_c}  |H(ν)|² S_x(ν) dν   （阻带，折叠成摩尔纹的能量）.
```

> 注：这是“每输出样本方差”的形式，故没有 1/s 因子；1/s 只在统计整段信号
> 总能量（样本数从 N 变成 N/s）时出现。代码里两种归一化都做了 Parseval 校验。

**这就是用户要的核心表达式：混叠能量 = 核传递函数模平方在阻带上对输入谱的积分。**
两种核代入各自的 FT，得到可直接计算的闭式：

```
盒式:  E_a^box   = ∫_{|ν|≥f_c} sinc²(π s ν) · S_x(ν) dν
高斯:  E_a^gauss = ∫_{|ν|≥f_c} exp(−4 π² σ² ν²) · S_x(ν) dν.
```

### 3.1 白噪声基准：核自身的阻带能量分数 Q(f_c)

取白输入 `S_x(ν) = const`，混叠能量占总能量的比例只取决于核，与输入无关：

```
Q(f_c) = ∫_{|ν|≥f_c} |H(ν)|² dν / ∫_R |H(ν)|² dν.
```

两个核都有闭式（s=4, f_c=0.125，数值与闭式在 `results/bounds.txt` 对账）：

- **高斯**：`|H|² = exp(−4π²σ²ν²)`，归一化后
  `Q_gauss = erfc(2πσ f_c) = 0.21430`（数值积分 0.21421，相对误差 < 0.1%）；
- **盒式**：`∫ sinc²(πsν) dν` 的原函数为
  `∫₀^U sinc²(v) dv = Si(2U) − sin²(U)/U`（U = π s ν 的无量纲变量），
  总能量 `∫_R sinc²(πsν)dν = 1/s`。在 U = πs f_c = π/2 处，单边带内占比为
  `(2/π)·[Si(2U) − sin²U/U]`，故
  `Q_box = 1 − (2/π)·[Si(2U) − sin²U/U] = 0.22631`（数值 0.22597）。

**结论：在相同等效半径下，白噪声激励的阻带泄漏盒式 0.226、高斯 0.214，
仅差约 6%，处于同一量级。** 高斯的视觉优势来自旁瓣的平滑包络（无振荡、无零点），
而不是总泄漏能量更小。这解释了为什么“换了高斯摩尔纹只是好些”——总泄漏没质变，
只是泄漏的频谱结构不再产生强拍频纹路。

## 4. 固定核宽下混叠能量的下界（不确定性原理）

### 4.1 时域—频域宽度不可能同时窄

对单位能量核 h（`∫h² = 1`），定义能量半径

```
r_E² = ∫ t² |h(t)|² dt,      r_ν² = ∫ ν² |H(ν)|² dν.
```

傅里叶不确定性原理给出严格下界

```
r_E² · r_ν² ≥ 1/(16 π²),
```

等号当且仅当 h 是高斯函数时取到。概率归一化版本（h 非负、∫h=1）形式相同：
`r_p² · r_ν,p² ≥ 1/(16π²)`。

数值核验（`bounds.txt`，离散 DTFT 一个周期内）：

| 核 | r_p² | r_ν² | 乘积 | 与下界 1/(16π²)=6.33e−3 比较 |
|---|---|---|---|---|
| 高斯（离散实现） | 1.2492 | 1.0134e−2 | 1.266e−2 | 高于下界（截断的有限抽头） |
| 盒式 | 1.2500 | 1.7193e−2 | 2.149e−2 | 约为下界的 3.4 倍 |
| 高斯（连续，精确） | σ² | 1/(16π²σ²) | **6.333e−3** | **精确取等** |

盒式核的乘积更大，意味着在相同空间半径下，它的频谱二阶矩更“散”——
这与它有重旁瓣相吻合。注意盒式核的**连续**频谱二阶矩是发散的
（`ν²sinc²(ν) ~ const` 不可积），这本身就是盒式核阻带抑制差的另一种表述；
表中盒式数字是离散 DTFT 单周期内的有限值。

### 4.2 从不确定性到混叠下界

阻带能量 `E_a = ∫_{|ν|≥f_c} |H|² S_x dν` 与频谱二阶矩直接挂钩。
对阻带区域有平凡不等式 `ν² ≥ f_c²`，于是（白输入下，能量归一化）

```
r_ν² = ∫ ν² |H|² dν ≥ f_c² · ∫_{|ν|≥f_c} |H|² dν = f_c² · Q(f_c) · E_tot,
```

即

```
Q(f_c) ≤ r_ν² / f_c²          （上界，用于直觉）
```

反过来配合不确定性原理 `r_ν² ≥ 1/(16π² r_E²)`，固定空间半径 r_E 就**锁死了
频谱能做到的最紧凑程度**：r_E 越小（核越窄、画面越锐），r_ν² 的下界越大，
任何核都无法把阻带能量压到该紧凑度允许的范围以下。对高斯族可以写成显式形式，
因为它取等号、且阻带能量有 erfc 闭式：

```
E_a^gauss(f_c; σ) = E_tot · erfc(2πσ f_c).
```

σ 增大（核变宽）时 erfc 单调下降，但这是以通带传递函数下降为代价的——下一节量化。

### 4.3 锐度约束反过来给混叠定下地板

“保持锐度”在频域上等于要求通带内传递函数足够接近 1。梯度能量（第 5 节定义）
由高频端主导，因此规定在某个通带频率 f_p ≤ f_c 处 `|H(f_p)| ≥ A`：

```
exp(−2π²σ² f_p²) ≥ A  ⇒  σ ≤ σ_max = √(−ln A / (2π² f_p²)).
```

σ 被封了顶，代入 erfc 就得到**锐度约束下的混叠能量地板**。取 A = 0.9、
f_p = f_c/2（s=4 时 f_p=0.0625）：

```
σ_max = 1.1689,    Q(f_c) ≥ erfc(2πσ_max f_c) = 0.19416 ≈ 19.4%.
```

也就是说：**只要还要求半 Nyquist 处保留 90% 的响应（画面不能糊），
即便用理论最优的高斯核，也至少有 ~19% 的白噪声能量要泄漏到阻带形成混叠。**
想要 Q 更小就必须增大 σ，立刻违反通带约束、画面变糊。这就是
“不能既无摩尔纹又保持锐度”的定量证明。

## 5. 锐度指标：梯度能量

锐度用输出的梯度能量（离散梯度的均方，1-D；2-D 为两方向之和）：

```
S = (1/M) Σ_m (y[m] − y[m−1])².
```

频域上梯度对应乘子 `(e^{j2πf} − 1)`，故

```
S = ∫ |e^{j2πf} − 1|² · S_y(f) df,
```

权重 `4 sin²(πf)` 随频率升高而增大，锐度主要由通带高频端决定——
与第 4.3 节的通带约束正好对应。为避免混叠本身冒充“锐度”（摩尔纹也是高频），
报告同时给出**基带梯度能量** `S_bb`：先把频谱掩码到 |ν|<f_c 再算梯度，
它只统计真正保留下来的细节，不含折叠纹路。比较以 S_bb 为准。

固定彩色噪声），全部 N 周期，循环卷积无边界跃变。每个数都用两条独立路径核算：
离散 DFT 掩码法（Parseval 校验，相对误差 ≤ 5e−3）与连续 FT 积分法。
完整数据在 `results/metrics.csv`。

| 4 | box | 1.118 | 6.53e−3 | 7.55e−3 | 0.66% | 0.1754 | 1.207 |
| 4 | gauss | 1.118 | 9.15e−3 | 7.79e−3 | 0.69% | 0.1797 | 1.341 |
| 4 | Lanczos-3 | — | 8.48e−4 | 8.48e−4 | 0.07% | 0.1845 | — |
| 8 | box | 2.291 | 5.90e−3 | 6.30e−3 | 0.58% | 0.1771 | 1.207 |

读图要点（`fig2_scales.png`）：

1. **同半径下盒/高斯混叠同量级**：s=4、s=8 两者 E_a 相差都在 10% 以内，
   与第 3.1 节白噪声基准（0.226 vs 0.214）一致。s=2 高斯反而更高，因为配平到
   盒式的小方差时高斯在 f_c 附近衰减还不够，而盒式 s=2 的第一零点恰在 f_c。
2. **锐度差异同样小**：S_bb 高斯略高（MTF50 更靠外，通带保持略好），
   但优势只有几个百分点。“高斯更糊”的主观感受更多来自它对极高频的整体滚降，
   而非通带内的显著损失。
3. **Lanczos-3 是真正的破局者**：靠负瓣在 f_c 附近构造深零点，混叠能量比盒/高斯
   **低一个数量级**（8.5e−4 vs ~7e−3），而基带锐度反而最高（0.18–0.21）。
   代价是核有负权重、会引入轻微振铃（ringing），且计算量更大。
4. **MTF50 > 1（×f_c）本身就是警告**：盒式 1.207、高斯 1.3–1.5，意味着
   |H| 掉到 0.5 的频率在输出 Nyquist 之外，阻带没有被有效截断——这正是摩尔纹存在的
   直接证据。理想抗混叠核的 MTF50 应落在 f_c 以内。

### 6.1 核宽扫描：权衡前沿

固定 s=4，让核宽从 2 扫到 9（高斯始终按 `(w²−1)/12` 配平，`results/sweep.csv`，
`fig3_tradeoff.png`）：

- 两核的混叠能量总体随核宽下降，但**盒式在 w≥7 后反弹**——sinc 旁瓣的零点位置
  随 w 移动，当零点错开 f_c 时泄漏回升；高斯无旁瓣，单调下降。
- 锐度随核宽单调下降，与混叠下降同步。右图把两者直接画成一条权衡前沿：
  沿曲线向“低混叠”走必然向“低锐度”走，**没有能向左上方（两者都好）移动的点**。
- 在最右端（w=9）高斯混叠比盒式低约 30 倍（6.1e−5 vs 1.9e−3），但这是靠
  大核宽换来的，此时两者锐度都已掉到 0.06 左右，画面明显发糊。

## 7. 对 vecgo 渲染器的具体建议

1. **现状**：`raster.Fill` 的 s² 超采样平均 = 盒式预滤波，sinc 旁瓣是边缘摩尔纹的
   来源；超采样只在 s 较大时才把 f_c 推得足够低，s 小（2×、4×）时旁瓣仍落在带内。
2. **同成本换高斯收益有限**：在相同等效半径/抽头预算下，高斯只能消除旁瓣振荡的
   视觉拍频，总混叠能量仅降约 6%，且会轻微增糊。若优先要“摩尔纹观感干净”可换，
   但不要期待能量级的改善。
3. **想要数量级改善，上带负瓣的核**：Lanczos-3（或更省的 Mitchell/猫Rom 核）
   在本实验把 E_a 压到 1/10 且不损失基带锐度，代价是负权重振铃和更高算力。
   矢量图形边缘锐利、内容多为几何边界，通常能接受轻微振铃。
4. **自适应策略**：平坦区域用窄核保锐度，检测到接近 Nyquist 的高频纹理区域
   （zone plate 类）自动切宽核或 Lanczos，让核宽随局部频谱走，绕开全局权衡。
5. 所有结论的代码可复现：`analysis/run_analysis.py`（数值引擎，含 Parseval 与
   闭式对账）、`analysis/make_figures.py`（4 张图）、`results/`（CSV 与 bounds.txt）。
