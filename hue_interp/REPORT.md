# 色相环感知均匀插值：从等角度分步到 CIEDE2000 弧长参数化

## 1. 问题的两层结构

| 层 | 现象 | 根因 |
|---|---|---|
| 拓扑层 | 跨过 180° 时插值路径突然跳一下、绕远路 | 朴素线性插值在角度域直接 `h(t)=h₀+t(h₁−h₀)`，没有取最短弧 |
| 度量层 | 前半段快、后半段慢，各步色差不等 | 角度均匀 ≠ 感知均匀：感知密度 `g(h)=dΔE/dh` 随色相变化 |

拓扑层用最短弧规则解决；**度量层是本题的主体**，需要先选定感知色差度量，再据此重新参数化。

## 2. 度量选择：CIEDE2000

选 **CIEDE2000（ΔE00，参数权重 k_L=k_C=k_H=1）**。理由：

- 它是目前 ISO/CIE 标准的感知色差公式，在 Lab 欧氏距离（ΔE76）之外显式修正了明度权重 S_L、彩度权重 S_C、**色相旋转项 R_T**（蓝紫区的感知交叉）和与色相相关的色相权重 S_H(h)；
- 正因为 S_H、R_T 含色相 h，沿等 L、等 C 的色相环走时，每度的感知代价不再是常数——等角度分步因此产生不等色差。对照之下，ΔE76 在 `L*=50, C*=50` 的 LCh 圆上给出严格常数密度 `g=C·π/180=0.87266 ΔE76/度`，无法刻画「前快后慢」。

实现（`colorlab.py`）的校验结果：与 colour-science 0.4.7 在 5000 对随机 Lab 上最大绝对偏差 **5.7×10⁻¹⁴**；Sharma et al. (2005) Table 1 七对参考数据全部吻合（如 2.0425、2.8615、3.4412、2.3669）；sRGB↔Lab 与参考库偏差 2.3×10⁻¹³。

两个色相环都纳入实验：

- **LCh 环**：CIELAB 中固定 `L*=50, C*=50` 的干净圆（主战场，无色域截断）；
- **HSL 环**：`S=1, L=0.5` 的经典色相轮（实际工程里更常见，路径在 Lab 中不是圆，青/品红附近色度趋近于零）。

## 3. 步长写成度量的函数

在角度 h 上定义**感知密度**（用 0.001° 网格上相邻点的 ΔE00 数值微分）：

```
g(h) = dΔE00/dh        单位：ΔE00 / 度
```

累积感知弧长（路径的泛函长度）：

```
S(h) = ∫ₕ₀ʰ g(u) du        S_total = S(h₁)
```

等角度分步时每一步的色差一阶近似为 `ΔE_i ≈ g(h_i)·Δh`，于是 g 大的地方一步走的感知距离就大（看着「快」），g 小的地方「慢」。把角度步长写成度量的函数：

```
dh/ds = 1/g(h)        ⇒        Δh_i ≈ Δs / g(h_i)
```

即**密度越大处角度步长越小**，密度越小处角度步长越大。实测密度：

| 环 | g_min | g_max | 整圈均值 | g_max/g_min |
|---|---|---|---|---|
| LCh(L50 C50) | 0.4008 | 0.6872 | 0.5100 ΔE00/度 | 1.71 |
| HSL(S1 L0.5) | 0.0317 | 1.6548 | 0.7718 ΔE00/度 | 52.15 |

HSL 的 52 倍悬殊直接解释了它肉眼可见的忽快忽慢（见 `fig_density.svg`）。

## 4. 最小化相邻步色差方差的参数化（变分结论）

把 N 步插值写成节点 `h₀<h₁<…<h_N`，每步感知长度 `d_i = ∫_{h_{i-1}}^{h_i} g(h)dh`，总长度受端点约束 `Σd_i = S_total`。最小化方差 `Var(d)= (1/N)Σd_i² − (S_total/N)²`：连续松弛下用拉格朗日乘子令 ∂/∂d_i 为零，得

```
d_1 = d_2 = … = d_N = S_total / N
```

**方差的全局最小值为零，且唯一由感知弧长等分时达到**——这正是弧长参数化 `S(h(t)) = t·S_total`（t∈[0,1]），反演 `h(t)=S⁻¹(t·S_total)`。等角度参数化只是 g(h) 为常数时的特例。

工程上给两个实现（`experiment.py`）：

1. **弧长反演**：在 0.001° 网格上累积 S，线性插值反求等 S 节点——微分意义精确；
2. **割线等化**（`equal_chord_hues`）：有限 N 时实际测量的是相邻节点的弦向 ΔE00 而非微分弧，再用不动点迭代把每一步的**实测弦长**等化，把离散化残差也压到机器精度。

**结论：三组端点上弧长参数化的方差均比等角度分步低 2–7 个数量级，割线等化在有限步下达到机器零方差**，满足「方差明显低于等角度分步」的要求。整圈（360°，12 步）基准：LCh 等角度 CV=15.40%，HSL 等角度 CV=50.87%，等化后均为 0。

## 6. 路径长度与角度差的比值 R

比值定义为弧段的**感知路径长度**（ΔE00 泛函积分，与参数化无关）除以角度跨度：

```
R = P / |Δh|,   P = ∫_{arc} g(h) dh     单位：ΔE00 / 度
```

对给定弧段 R 是一个确定常数——它是该弧上 g(h) 的加权平均；只有在 ΔE76 等均匀度量下它才对所有弧取同一个普适常数（LCh 环解析值 `C·π/180 = 0.87266`）。ΔE00 下逐弧计算：

| 端点 (°) | 角度跨度 | LCh：P (ΔE00) | **R (ΔE00/度)** | HSL：P (ΔE00) | **R (ΔE00/度)** |
|---|---|---|---|---|---|
| 350→10 | 20° | 8.8084 | **0.44042** | 8.6522 | **0.43261** |
| 0→180 | 180° | 89.9740 | **0.49986** | 154.7803 | **0.85989** |
| 20→260 | 120° | 63.2618 | **0.52718** | 84.3375 | **0.70281** |
| 整圈参考 | 360° | 183.6051 | 均值 0.51001 | 277.8618 | 均值 0.77184 |

同一环上不同弧的 R 不同，正是 g(h) 非均匀的积分体现；它同时给出每一步的目标色差 `d* = P/N = R·|Δh|/N`，可直接用于实现。

## 7. 180° 跳变量（度）——三组端点排成三行

最短弧规则取有符号角差 `Δh = ((h₁−h₀+180) mod 360) − 180 ∈ (−180, 180]`。朴素角差 raw 与最短弧角差之差 `J = raw − Δh`（必为 ±360° 的整数倍）即绕远路被纠正的跳变量；同时列出 t=0.5 中点因此发生的位置跳变：

| 端点 (°) | 朴素角差 raw | 最短弧 Δh | **跳变量 J（度）** | 朴素中点 | 最短弧中点 | 中点跳变 |
|---|---|---|---|---|---|---|
| 350 → 10 | −340° | +20° | **−360°** | 180° | 0° | 180° |
| 0 → 180 | +180° | −180°（对跖点，两弧等长） | **+360°（约定符号）** | 90° | 270° | 180° |
| 20 → 260 | +240° | −120° | **+360°** | 140° | 320° | 180° |

对跖点附近的不连续性扫描（固定 h₀=0）说明「突然跳一下」的机制：h₁=179.9° 时中点在 89.95°，h₁=180.1° 时中点翻到 270.05°——**端点只动 0.2°，中点跳变 180.000°，有符号角差整体翻转 360°**。工程上对恰为 180° 的对跖情形需固定一个方向约定（本表取负向），避免结果随浮点抖动在两条等长弧之间来回翻转。

## 8. 复现方式

```bash
python -I hue_interp/validate.py      # ΔE00/色彩空间校验（对照 colour-science + Sharma 数据）
python -I hue_interp/experiment.py    # 主实验，输出 results.json 与全部表格数值
python -I hue_interp/equalize.py      # 割线等化（有限步精确解）
python -I hue_interp/make_figures.py  # 生成 fig_density.svg / fig_strips.svg
```

- `colorlab.py`：sRGB↔XYZ↔Lab↔LCh、HSL、CIEDE2000（Sharma 2005 公式）；
- `experiment.py`：密度 g(h)、弧长反演、割线等化、三组端点统计、R 与跳变量；
- 图表：`fig_density.svg`（两环的 g(h) 曲线）、`fig_strips.svg`（三组端点等角度 vs 等化分步色条，悬停可见每步色相与 ΔE00）。

## 附：实现层面的两条实用规则

1. 先做拓扑：`Δh = wrap(h₁−h₀)` 取最短弧，对跖点固定方向约定；
2. 再做度量：预算一条 360° 的累积弧长查找表 S(h)，插值时 `h = S⁻¹(S(h₀) + t·(S(h₁)−S(h₀)))`，每节点 O(log n)；要求有限步严格等色差时再跑割线等化不动点迭代（本实验 60 次内收敛到 10⁻¹²）。
