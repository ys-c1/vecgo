# 三步坐标变换的误差预算与小数位分配

## 1. 问题与三步分解

现有 `pipe.Transform` 把缩放和旋转熔在一次 float64 运算里，精度只标了“待定”。
这里把坐标变换显式拆成三步，每步输出按 **dᵢ 位小数十进制量化**（四舍五入，
单坐标舍入误差 |eᵢ| ≤ 0.5·10⁻ᵈⁱ）：

| i | 阶段 | 映射 | 雅可比 Jᵢ |
|---|------|------|-----------|
| 1 | 缩放 | q₁ = k·p | kI（各向同性） |
| 2 | 旋转 | q₂ = R(θ)·q₁ | R(θ)，c=cosθ, s=sinθ |
| 3 | 平移 | q₃ = q₂ + (tx,ty) | I |

## 2. 每步雅可比的条件数

谱条件数 κ₂ = σmax/σmin：

- 缩放 kI：奇异值 {k,k}，**κ₂ = 1**（各向同性，不改变方向间相对误差）；
- 旋转 R(θ)：正交阵，奇异值 {1,1}，**κ₂ = 1**；
- 平移 I：**κ₂ = 1**。

三步 κ₂ 都为 1，说明没有任何一步在谱范数意义下“病态”；但十进制舍入是按
**分量最坏情况**传播的，正确的放大倍数要用无穷范数。链式法则下，第 i 步的
分量误差传播到最终输出端的放大倍数为

```
a₁ = ‖R(θ)‖∞·‖I‖∞ = |c|+|s|,   a₂ = ‖I‖∞ = 1,   a₃ = 1
```

其中 ‖R(θ)‖∞ = |cosθ|+|sinθ| **随角度变化，取值区间 [1, √2]**（45° 取到 √2）。
这就是旋转步误差放大倍数“随角度变、不能按常数摊”的定量来源：缩放量化误差
要再过一次旋转，被放大最多 √2 倍，而旋转、平移步之后没有旋转，放大恒为 1。

## 3. 连续误差预算：按条件数（放大倍数）反比分配

设总误差上界为 E（输出端单分量），n=3。线性化传播模型下总误差

```
e = a₁e₁ + a₂e₂ + a₃e₃,   |e| ≤ Σ aᵢ·(0.5·10⁻ᵈⁱ)
```

先在连续域按放大倍数反比摊预算（aᵢ 越大、预算越小）：

```
εᵢ = E / (n·aᵢ)          （恰好有 Σ aᵢεᵢ = E，预算用满）
```

对应的连续理想位数

```
xᵢ = log10( aᵢ / (2εᵢ) ) = log10( n·aᵢ² / (2E) )
```

注意是 aᵢ 的平方进对数：放大倍数同时压缩预算和抬高该步自身的精度要求。

## 4. 取整策略（一行）与不超界证明

> **dᵢ 全部从 0 起；只要 Σ aᵢ·0.5·10⁻ᵈⁱ > E，就把当前 aᵢ·0.5·10⁻ᵈⁱ 最大的
> 那一步 dᵢ 加 1，直到上界 ≤ E。**

为什么不用“逐位独立 ceil(xᵢ)”：实测它在整数边界上会过度保守——例如
θ≈294°、E=1.79e-3 时独立 ceil 给 10 位，而等精度方案只需 9 位（测试
`TestAdaptiveNoMoreDigitsThanEqual` 曾复现该失败）。原因是各步独立向上取整
无法把一步省下的位让给另一步。

**不超界证明**：循环终止条件即 Σ aᵢ·0.5·10⁻ᵈⁱ ≤ E，故取整后方案的保证上界
天然不越界；每次只做 +1（向更精确方向），浮点比较留 1e-12 容差只可能多给
位、不可能少给位。

**全局最优证明（总位数最少）**：把第 i 步从 t 位提到 t+1 位，其边际误差收益
恒为

```
aᵢ·0.5·10⁻ᵗ − aᵢ·0.5·10⁻⁽ᵗ⁺¹⁾ = 0.45·aᵢ·10⁻ᵗ
```

与其他步取几位无关，且对固定的 i 随 t 严格递减。贪心每次取走当前全局最大
的可用边际收益，因此它最终选中的 m 个收益，正是所有步所有层级全体边际收益
中最大的 m 个；任何总位数为 m 的其他整数方案，其收益集合不可能更大。
⇒ 贪心以最小的 m（总位数）使总误差降到 ≤ E。该结论另有 300 组随机参数下
对 dᵢ∈[0,10] 全枚举的暴力验证（`TestGreedyIsGloballyOptimal`）。

E=1e-4（更紧预算，省位依旧成立：14 vs 15）：

| 角度 | 自适应实测最坏 | 自适应保证上界 | 等精度实测最坏 | 等精度保证上界 |
|------|--------------|--------------|--------------|--------------|
| 0°  | 5.499998e-05 | 6.000e-05 | 5.000000e-06 | 1.500e-05 |
| 30° | 6.156567e-05 | 6.183e-05 | 1.173977e-05 | 1.683e-05 |
| 45° | 6.192443e-05 | 6.207e-05 | 1.196687e-05 | 1.707e-05 |

结论：

1. 两方案实测最坏误差都低于各自保证上界、且都低于 E——**同一误差上限下
   自适应方案总位数严格更少（8<9，14<15）**；
2. 自适应方案的保证上界更贴近 E（预算用得更满），等精度方案为统一位数
   付出了系统性过采样；
3. 实测/保证之比在各角度稳定（约 0.92~0.998），说明分量最坏情况模型
   与实际舍入行为一致，没有隐藏的超界方向。

## 7. 代码与复现

- `pipe/precision/precision.go`：条件数 `Conditions`、预算与贪心整数化
  `PlanAdaptive`、等精度对照 `PlanEqual`、量化流水线 `Apply`/`Exact`；
- `pipe/precision/precision_test.go`：κ₂ 恒为 1、2000 组参数保证上界不超界、
  贪心对全枚举的全局最优性、20 万点实测、方案对比；
- `cmd/precision-report`：打印条件数表、逐行位数表与百万点实测总误差，
  `go run ./cmd/precision-report 0.01`（或传任意 E）。

集成方式：渲染管线需要落点位时，用 `PlanAdaptive` 求出 `[3]int` 位数，
对每个顶点调 `precision.Apply` 替换现有的熔合 `pipe.Transform` 即可；
E 的选取建议绑定到亚像素尺寸（如 E = 1/(2·Width·Supersample)）。
