# 保单调三次插值限制器：一阶导约束推导

## 1. 问题

渐变颜色由控制点 `(x_k, y_k)` 经分段三次 Hermite 插值生成。标准
Catmull-Rom 只保证曲线**经过控制点**，不保证区间内单调：当相邻割线斜率
差异很大时（例如渐变经过暗部后陡亮、或在局部极值两侧），三次段会越过
端点值，表现为暗部边缘的**回勾/过冲**，插值序列非单调。

目标：只修正控制点处的一阶导（切线）`m_k`，使每个区间 `[x_k, x_{k+1}]`
上的三次段保持与割线同方向的单调性，且曲线仍精确经过全部控制点。

## 2. 三次 Hermite 段及其一阶导

记区间长度 `h_k = x_{k+1} − x_k`，割线斜率

```
Δ_k = (y_{k+1} − y_k) / h_k
```

令 `t = (x − x_k)/h_k ∈ [0,1]`，Hermite 段为

```
H(t) = h00(t) y_k + h10(t) h_k m_k + h01(t) y_{k+1} + h11(t) h_k m_{k+1}
h00 = 2t³−3t²+1,  h10 = t³−2t²+t,  h01 = −2t³+3t²,  h11 = t³−t²
```

对 x 求一阶导（链式法则多除一个 h_k）：

```
H'(x) = Δ_k + (m_k − Δ_k)·(3t² − 4t + 1) + (m_{k+1} − Δ_k)·(3t² − 2t)
```

引入无量纲切线（相对于割线的比值）

```
α = m_k / Δ_k,        β = m_{k+1} / Δ_k
```

整理得 `q(t) ≜ H'(x)/Δ_k`：

```
q(t) = (2α + β − 3) t² + (3 − α − 2β) t + α
     = A t² + B t + α
A = 2α + β − 3,   B = 3 − α − 2β
q(0) = α,   q(1) = β
```

## 3. 单调性的一阶导约束（不等式组）

### 3.1 非负性要求

- 若 `Δ_k > 0`（区间上升），单调非降要求 `H'(x) ≥ 0 ⇔ q(t) ≥ 0`；
- 若 `Δ_k < 0`（区间下降），单调非升要求 `H'(x) ≤ 0 ⇔ q(t) ≥ 0`
  （除以负数翻转不等号，比值形式完全相同）；
- 若 `Δ_k = 0`（平台），要求 `H' ≡ 0`，即 `m_k = m_{k+1} = 0`。

因此统一约束为：**α ≥ 0、β ≥ 0，且 q(t) 在整个 [0,1] 上非负。**

### 3.2 二次函数非负的分情况讨论

**情况一：A ≤ 0（q 开口向下或为直线）。** 二次函数在闭区间上的最小值
出现在端点，故 `q ≥ 0 ⇔ α ≥ 0 且 β ≥ 0`。代入 A：

```
A ≤ 0  ⇔  2α + β ≤ 3
```

**情况二：A > 0（开口向上），顶点在区间左侧或左侧以外**
（对称轴 `t* = −B/(2A) ≤ 0 ⇔ B ≥ 0`）：最小值在 t=0，只需 `α ≥ 0`。

```
B ≥ 0  ⇔  α + 2β ≤ 3
```

**情况三：A > 0 且 B < 0（顶点落入 (0,1)，此时 C=α≥0 自动保证
t* < 1）。** 最小值为顶点值，要求 `q(t*) ≥ 0 ⇔ B² ≤ 4Aα`。展开
（27 项全部消去后）：

```
α² + αβ + β² − 6α − 6β + 9 ≤ 0
```

记椭圆约束 `E(α,β) ≜ α²+αβ+β²−6α−6β+9 ≤ 0`。

### 3.3 完整不等式组（精确充分必要条件）

```
α ≥ 0,  β ≥ 0,
( 2α + β ≤ 3 )  ∨  ( α + 2β ≤ 3 )  ∨  ( E(α,β) ≤ 0 )
```

平台区间 `Δ_k = 0` 单独处理：`m_k = m_{k+1} = 0`。

## 4. 解出允许的切线区间

固定 α，对 β 求解。椭圆方程 E=0 关于 β 是二次方程：

```
β² + (α−6)β + (α²−6α+9) = 0
判别式 D = (α−6)² − 4(α²−6α+9) = 3α(4−α)
```

D ≥ 0 要求 `0 ≤ α ≤ 4`，椭圆内弧（下根）与外弧（上根）为

```
β_∓(α) = (6 − α ∓ √(3α(4−α))) / 2
```

区域中两条直线 `2α+β≤3`、`α+2β≤3` 只覆盖下腹部（β 较小处），
决定**外边界**的恒为椭圆外弧。因此精确允许区间为

```
            ⎧ 0 ≤ β ≤ β_+(α) = (6 − α + √(3α(4−α)))/2,  0 ≤ α ≤ 4
可行解 (α,β) ⎨
            ⎩ 无解,  α < 0 或 α > 4
```

由对称性交换 α、β 结论不变。几个边界点（代码中数值核对过）：

| α | βmax | 含义 |
|---|------|------|
| 0 | 3 | 一端切线为 0，另一端最多 3Δ |
| 1 | 4 | 椭圆最外点 (1,4)/(4,1) |
| 2 | 2+√3 ≈ 3.732 | |
| 3 | 3 | (3,3) 恰在椭圆上 |
| 4 | 1 | 可行域尽头 |

### 保守圆约束（实现采用）

精确区域边界含开方与分支判断，Fritsch–Carlson 给出其内接的简单充分条件：

```
α² + β² ≤ 9
```

它完全落在精确区域内：在圆上 β²=9−α²，可验证
`2α+β≤3 ∨ E≤0` 恒成立（(3,3) 处两者同时取等）。圆内可行 α 的范围是
`0 ≤ α ≤ √(9−β²) ≤ 3`，区间形式的允许范围即

```
0 ≤ α ≤ √(9 − β²),   0 ≤ β ≤ 3   （对称地约束另一端）
```

## 5. 限制器算法

### 5.1 初始切线（未加限制器的原始行为）

- 端点：`m_0 = Δ_0`，`m_{n−1} = Δ_{n−2}`；
- 内点（三点加权，非均匀 Catmull-Rom）：

```
m_k = (h_k Δ_k + h_{k−1} Δ_{k−1}) / (h_{k−1} + h_k)
```

### 5.2 生效判据：相邻切线同号检查

逐内点 k 检查相邻割线 `Δ_{k−1}` 与 `Δ_k`：

```
Δ_{k−1} · Δ_k > 0   同号：控制点在单调段内部，限制器生效（进入 5.3）
Δ_{k−1} · Δ_k = 0   一侧是平台：m_k ← 0
Δ_{k−1} · Δ_k < 0   异号：控制点是局部极值，m_k ← 0
```

检查方式即对两个割线斜率取乘积的符号（等价于
`sign(Δ_{k−1}) == sign(Δ_k)`，乘积形式同时覆盖平台 Δ=0 的情形）。
极值/平台处切线必须为 0，否则三次段会在控制点附近反向鼓包。

### 5.3 区间缩放（保守圆）

逐区间 k 计算 `α = m_k/Δ_k, β = m_{k+1}/Δ_k`（`Δ_k=0` 时两端置 0）。
若 `α²+β² > 9`，按共同因子

```
τ = 3 / √(α²+β²)
```

同时缩放 `m_k ← τ·m_k`、`m_{k+1} ← τ·m_{k+1}`。一条切线被左右两个区间
共享，故外层迭代直到没有区间越界（迭代中切线只减不增，必然收敛；
代码设 64 次上限兜底）。

### 5.4 性质

1. 控制点函数值从不修改，Hermite 基函数保证 `H(0)=y_k, H(1)=y_{k+1}`，
   曲线仍精确经过全部控制点；
2. 每个区间 `q(t)≥0`，区间内不过冲、不回勾，整段单调；
3. 线性数据上 `m_k ≡ Δ_k ⇒ α=β=1`，圆约束 `1+1≤9` 恒不触发，
   限制器为 no-op，原始形状完全保留。

## 6. 控制点处切线的单独验证

代码 `interp/interp_test.go` 的 `TestKnotTangents` 对每条限制后的样条
逐控制点、逐区间单独断言：

1. 相邻割线乘积 `≤ 0` 的控制点，切线严格等于 0；同号控制点的切线与割线
   同号；
2. 平台区间（Δ=0）两端切线均为 0；
3. 每个区间 `α,β ≥ 0` 且 `α²+β² ≤ 9`（保守圆）；
4. 每个区间同时满足精确区域：双向调用 `ExactBetaMax`，核对
   `β ≤ βmax(α)` 与 `α ≤ βmax(β)`；
5. `KnotError()` 验证各控制点处求值与给定 y 的偏差为 0（机器精度内）。

`TestExactBetaMaxNumeric` 再用 2000 点/段的数值扫描反推可行 β 边界，
与第 4 节的解析解逐项核对。
