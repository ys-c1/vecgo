# 渐变切线修复：同号约束 → 允许区间 → 凸二次目标的最优切线

客户渐变图暗部有一段“往回勾”。定位为三次 Hermite 插值在坡度陡/缓切换处把
节点切线取大了（朴素 Catmull-Rom 平均切线 `m_k=(d_{k-1}+d_k)/2`），曲线冲出
相邻控制点的值域再返回，形成过冲。本目录给出：

1. 约束怎么给出一条切线的**允许闭区间**；
2. “贴合原控制点”的目标函数 `J(t)=At²−2Bt+C` 与无约束驻点闭式；
3. 最优解为什么只能落在**左端点 / 右端点 / 内部驻点**，并各给一组数；
4. 同一张客户渐变图修复前/后的**过冲像素数**，以及亮部核对的**一个偏离量**。

数值唯一真源是可执行命令：

```bash
go run ./cmd/rampreport artifacts     # 产出 PGM、ramp_report.json、三组数
go test ./ramp/                       # 约束、闭式、三种情形、零过冲回归
```

## 1. 三次 Hermite 段

控制点 `(x_i,y_i)`，`x_i` 严格递增。记

```
h_i = x_{i+1}-x_i,  d_i = (y_{i+1}-y_i)/h_i   # 第 i 段弦斜率
m_i = 节点 i 的切线 (dy/dx)
u   = (x-x_i)/h_i ∈ [0,1]
```

第 i 段：

```
C_i(u) = h00(u)y_i + h10(u) h_i m_i + h01(u)y_{i+1} + h11(u) h_i m_{i+1}
h00=2u³-3u²+1, h01=-2u³+3u², h10=u³-2u²+u, h11=u³-u²
```

Hermite 严格过两个端点，所以“在控制点取值处”偏离恒为 0（见第 6 节）。

事故切线（`Curve.NaiveTangents`）：

```
m_0=d_0, m_{n-1}=d_{n-2}, m_k=(d_{k-1}+d_k)/2
```

## 2. 约束与一条切线的允许区间

只要求“相邻切线同号”，得到的是**半直线**：待求切线 `t=m_k` 必须与左右弦斜率
`dL=d_{k-1}`、`dR=d_k` 同号，也即与邻切线 `a=m_{k-1}`、`b=m_{k+1}` 同号。
要得到题目所说有**两个端点的闭区间**，还需要一个幅值上界。采用保证三次段
单调、不过冲的标准 **Fritsch–Carlson 圆界**：一段上令 `α=m_i/d_i`、`β=m_{i+1}/d_i`，
则 `α²+β²≤9` 是单调区域的充分条件。

对中间节点 k，固定 `a,b`，两个相邻段分别要求

```
(a/dL)² + (t/dL)² ≤ 9  ⇒ |t| ≤ |dL|·√(9-(a/dL)²)
(t/dR)² + (b/dR)² ≤ 9  ⇒ |t| ≤ |dR|·√(9-(b/dR)²)
```

再叠加同号条件，得到允许区间（`FCInterval`）：

```
dL·dR > 0, dL<0 : [lo,hi] = [-R, 0]
dL·dR > 0, dL>0 : [lo,hi] = [ 0, R]
其中 R = min( |dL|√(9-(a/dL)²), |dR|√(9-(b/dR)²) )

dL·dR ≤ 0 或有零弦斜率 : 数据本身在此转折，安全切线为 0，[lo,hi]=[0,0]
```

> 仅“同号”给出 `[0,+∞)` 或 `(-∞,0]` 的符号半边；FC 圆界补上有限的外端点
> `±R`。这正是后面“左/右两个端点情形”都能出现的原因。

## 3. 贴合度目标函数与最优切线闭式

曲线已经精确过控制点，所以“贴合原控制点”有意义的连续写法，是让它尽量贴近
控制点张成的**分段线性控制折线** `L(x)`（也就是没有三次切线自由度时的形状）。
只动一个节点切线 `t=m_k` 时，只有左右两段受影响。

令 `q(u)=2u³-3u²+u`。在一段上三次曲线减弦为
`h·(邻切线 h10 + t h11 - d·q)`（右段把 h10/h11 与两个切线对调）。于是

```
J(t) = ∫_{x_{k-1}}^{x_{k+1}} (C_t(x)-L(x))² dx
     = hL³∫₀¹(a h10 + t h11 - dL q)² du
     + hR³∫₀¹(t h10 + b h11 - dR q)² du
     = A t² - 2B t + C
```

用到的精确积分常数：

```
∫h10² = ∫h11² = 1/105
∫h10·h11 = -1/140
∫q² = 1/210
∫q·h10 = ∫q·h11 = 1/420
```

展开得到

```
A = (hL³+hR³)/105  > 0
B = [ hL³(dL+3a) + hR³(dR+3b) ] / 420
τ = B/A = [ hL³(dL+3a) + hR³(dR+3b) ] / [4(hL³+hR³)]     # 内部驻点
```

`τ` 还有个直观解释：它是两侧“局部偏好切线” `(dL+3a)/4`、`(dR+3b)/4`
按 `hL³:hR³` 的凸组合。常数项

```
C = hL³(a²/105 + dL²/210 - a·dL/210)
  + hR³(b²/105 + dR²/210 - b·dR/210)
```

（`Quadratic` 用同一组常数直接计算，测试用中心差分核对了 `J'(τ)=0`。）

## 4. 为什么最优只可能在端点或内部驻点

`J''(t)=2A=2(hL³+hR³)/105>0`，所以 `J` 是**严格凸二次**，在闭区间 `[lo,hi]`
上有唯一最小值。凸二次在闭区间上的投影极小化给出

```
              ⎧ lo,  τ < lo          情形① 左端点
t_opt = clamp(τ,lo,hi) = ⎨ τ,  lo ≤ τ ≤ hi     情形③ 内部驻点（J'=0）
              ⎩ hi,  τ > hi          情形② 右端点
```

理由是穷尽的：若 `τ` 在区间内，费马定理 `J'=0` 给出内部驻点且严格凸保证它
就是全局最优；若 `τ<lo`，整条 `[lo,hi]` 都在对称轴右侧、`J` 单调上升，最小在
`lo`；`τ>hi` 同理最小在 `hi`。若 `lo=hi`（数据转折），退化为唯一端点 `0`。

对全部内部节点轮流做这个一维精确投影并扫描到收敛（`Curve.Optimize`），
就得到整段渐变的约束最优切线；每一步都在降低同一个凸目标的对应坐标。

## 5. 三种情形，各一组数

统一取 `hL=hR=1, dL=dR=-1`（下降渐变），只改两个固定邻切线 `a,b`。
`A=2/105≈0.019047619`。完整机器读数见 `artifacts/ramp_report.json: three_cases`，
函数图见 `artifacts/three_cases.png`。

### 情形① 最优 = 左端点 `lo`（幅值端点）

`a=b=-2.4=-12/5`。

```
R = √(9-(12/5)²) = 9/5 = 1.8 ,  [lo,hi]=[-1.8, 0]
τ = (-1+3(-2.4))/4 = -2.05 = -41/20   (< lo=-1.8)
B=-41/1050≈-0.039047619, C≈0.096380952
t_opt = lo = -1.8
J(lo)=J*=0.017523810 ;  J(τ)=0.016333333（更小但 τ 不可行）; J(0)=C=0.096380952
```

### 情形② 最优 = 右端点 `hi`（同号/符号端点）

固定邻切线符号是错的：`a=b=+1`。

```
R = √(9-1) = 2√2 ≈ 2.828427 ,  [lo,hi]=[-2.828427, 0]
τ = (-1+3·1)/4 = +0.5          (> hi=0)
B=1/105≈0.009523810, C=4/105≈0.038095238
t_opt = hi = 0                  （同号约束把它钉在 0）
J(0)=J*=0.038095238 ; J(τ)=1/30≈0.033333333（不可行）; J(lo)≈0.244351
```

### 情形③ 最优 = 内部驻点 `τ`

`a=b=-1`（两端切线都等于弦斜率，Hermite 退化为直线）。

```
[lo,hi]=[-2.828427, 0]
τ = (-1-3)/4 = -1               (在区间内)
B=-1/105≈-0.019047619, C=2/105≈0.019047619
t_opt = τ = -1
J*=J(-1)=0 ;  J(0)=0.019047619 ; J(lo)≈0.063678967   （驻点严格优于两端）
```

客户数据自身也在节点 k=4、k=5 上真实落到“左端点”（见 JSON `knot_solutions`）：
例如 k=4（x=0.58）`τ≈-0.5240 < lo≈-0.2993`，故 `t_opt=lo=-0.2993`，
把事故切线 `-0.8533` 收回到 FC 圆界上。

## 6. 同一张客户图：过冲像素 4608 → 0

客户控制点（严格单调下降；x≥0.58 是陡坡后的平暗尾）：

| i | x | y | 朴素 m | 最优 m |
|---|----|------|--------|--------|
| 0 | 0.00 | 0.970 | -0.8000 | -0.8000 |
| 1 | 0.15 | 0.850 | -1.1500 | -1.0180 |
| 2 | 0.30 | 0.625 | -1.5500 | -1.1480 |
| 3 | 0.45 | 0.385 | -1.6000 | -1.0100 |
| 4 | 0.58 | 0.177 | -0.8533 | **-0.2993（=lo）** |
| 5 | 0.73 | 0.161 | -0.1133 | **-0.1133（=lo）** |
| 6 | 0.88 | 0.143 | -0.1017 | -0.1043 |
| 7 | 1.00 | 0.133 | -0.0833 | -0.0833 |

扫描 **29** 轮收敛（末轮最大变动 `7.99e-15`），`FCFeasible=true`。

过冲像素定义：像素灰阶落在其所在三次段两端控制点灰阶（同一 `Byte=round(255y)`
量化）所张区间之外即计数；全行同值，故“问题行数 × 图宽”。量化单调，修复后
曲线单调，不会有假阳性。

| 图 | 修复前 | 修复后 |
|----|-------:|-------:|
| 256² `gradient_before/after_256.pgm` | **4608 像素**（18 行 ×256，最大超出 2 灰阶） | **0** |
| 64² `gradient_before/after_64.pgm` | **320 像素**（5 行 ×64，最大超出 2 灰阶） | **0** |
| 连续密采（每段 800 点） | 516 个采样越界，最大越界 `0.006446` 强度 | **0 点，0** |

可视化：`artifacts/ramp_fix_overview.png`（红=修复前，暗部明显冲出 0.177 后回勾；
绿=修复后，单调贴弦）。

### 亮部核对，偏离量写成一个数

亮部取控制点 0–3（y = 0.970 / 0.850 / 0.625 / 0.385）。在这些点的精确 x 处
核对曲线取值与控制点取值：

```
δ_bright = max_{i∈{0,1,2,3}} | C_opt(x_i) - y_i | = 0.000000   ← 题目要的“一个数”
```

256² 成图上取最近输出行核对 8-bit 灰阶，最大偏离也是 **0 级**。
（辅助的形状量，不是这个数：亮部三次曲线离控制折线的最大拱离为 `0.009307`
强度单位。64² 图若用“最近行”而非精确 x 核对，会因最近行偏离控制点最多半个
行格而读到 2 个灰阶——那是子行采样误差，不是控制点取值偏离；精确控制点核对
仍是 δ=0。）
