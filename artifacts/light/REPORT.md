# 感知亮度守恒权重 · 三组强度亮度对照 · 非线性迭代残差 · 覆盖率取点

**结论先行。** 不按线性总能量归一，而按**感知亮度守恒**求灯组增益权重 `w`：
`P(w(I1+I2)) = P(I1)+P(I2)`。感知定义取 CIE L\* 归一化明度
`P(Y)=L*(Y)/100`（灰度下 `Y=I`）。该方程非线性，用解析导数 Newton +
二分保护求解，判据 `|F|≤1e-13 且 |Δw|≤1e-14(1+|w|)`，三组分别
**6 / 6 / 5 次**迭代收敛，末残差 **0 / 1.11e-16 / 0**（float64 机器地板），
与可逆闭式解的相对差 ~2e-16。朴素线性归一（两灯各 `1/2`、输出 `S/2`）的
亮度与感知守恒亮度并列于下表。**单光源走精确恒等分支（w=1、输出=输入、
0 迭代），默认渲染产物三个 sha256 与改动前逐字节相同**，由测试锁定。

## 1. 感知亮度的定义

彩色 Rec.709/sRGB 线性亮度 `Y=0.2126R_lin+0.7152G_lin+0.0722B_lin`；
本仓灰度 `R=G=B=I ⇒ Y=I`。CIE 1976：

```
L*(Y)=116 f(Y)-16
f(Y)=Y^(1/3),                                  Y>(6/29)^3
    =Y/[3(6/29)^2]+4/29 = κY/116（故 L*=κY）,  Y≤(6/29)^3
ε=(6/29)^3=216/24389≈0.00885645, κ=24389/27≈903.2963
P(Y)=L*(Y)/100
```

完整推导、逆函数、gamma2.2 备选口径与适用性见
[`docs/perceptual-light-weights.md`](../../docs/perceptual-light-weights.md)。

## 2. 三组强度：两种归一的亮度并列（同一把 L\* 尺）

| 组 | `(I1,I2)` | 线性归一 `w_L`/输出 | **线性归一亮度 L\*** | 感知权重 `w*`/输出 | **感知归一亮度 L\*** | 目标 `L*(I1)+L*(I2)` |
|---|---|---|---:|---|---:|---:|
| **G1** 等高暗调 | `.10,.10` | .5 / .100 | **37.8424** | 2.468817166 / .493763 | **75.6849** | 75.6849 |
| **G2** 强主弱辅 3:1 | `.18,.06` | .5 / .120 | **41.2161** | 2.282081294 / .547700 | **78.9086** | 78.9086 |
| **G3** 深暗跨线性趾 | `.012,.004` | .5 / .008 | **7.2264** | 1.099653786 / .017594 | **14.1706** | 14.1706 |

归一化 P 值：线性归一 `0.378424305 / 0.412161201 / 0.072263704`；
感知归一 `0.756848609 / 0.789085722 / 0.141705556`。

**“亮两倍”与“发灰”背景量化**：原始线性相加 `w=1` 时 G1 的 `S=.2=2×.1`
（两倍能量），但 `L*(.2)=51.8372`，并非 `2L*(.1)=75.6849`；三组原始相加
亮度为 `51.8372 / 56.0878 / 13.2302`，都低于感知和。线性比例权重
`I_i/S` 是无绝对尺度的比例，若误当灰度输出会把暗灯抬到中灰——这是
“直接归一让暗部发灰”的典型来源；守恒方程保留绝对强度目标，且黑始终为 0。

## 3. 非线性求解：迭代次数与残差

方程 `F(w)=P(wS)-T=0`，`T=min(P(I1)+P(I2),1)`；解析导数 Newton，
二分区间保护，初值 `w0=1`。判据 `|F|≤1e-13 且 |Δw|≤1e-14(1+|w|)`，上限 50。

| 组 | **迭代次数** | **末残差 `|F|`** | 收敛 | 路径 | 与闭式 `w*=P⁻¹(T)/S` 相对差 |
|---|---:|---:|:---:|---|---:|
| G1 | **6** | **0** | ✓ | newton | 1.80e-16 |
| G2 | **6** | **1.11×10⁻¹⁶** | ✓ | newton | 1.95e-16 |
| G3 | **5** | **0** | ✓ | newton | 2.02e-16 |

G1 残差轨迹 `2.385e-1 → 5.444e-2 → 3.115e-3 → 1.056e-5 → 1.217e-10 → 0`
（对应第 1…6 轮），标准二次收敛。逐轮 `w_k/步长/保护位` 见
`table.generated.md` 与 `results.json` 的 `trace`。`0` 是 float64 上的精确根
（差小于一个 ULP），非零残差与 ~2e-16 的闭式偏差共同表明已到机器地板。

## 4. 覆盖率—位置函数（三点）

单位像素直边 `x=c`（留左）：`C(x)=clamp(x,0,1)`。

| 位置 `x` | **覆盖率 `C(x)`** | 截断灰度 `uint8(255C)` | 16×SS 对照 |
|---:|---:|---:|---|
| 0.25 | **0.25** | 63 | 64/256 = .25，差 0 |
| 0.50 | **0.50** | 127 | 128/256 = .50，差 0 |
| 0.75 | **0.75** | 191 | 192/256 = .75，差 0 |

`C(0)=0、C(1)=1`（整数位置只取 0/1）。G1 权重落到这三点的有效亮度
`L*(w·C·S)` 为 `41.7578 / 56.7703 / 67.3012`。原始三点数据见
`coverage_points.csv`。
