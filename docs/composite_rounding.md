# 多层半透明叠合的定点舍入误差报告

颜色归一在 [0,1]，一档 = 8 位输出相邻两值之间的距离（1/255）。
误差表里的 ε_i、δ_i、界、偏差都**以档为单位**，一档 = 1.0。

## 累积式

叠合从底到顶按 over 递推，第 i 层精确值为 `C_i = (1−α_i)·C_{i−1} + α_i·c_i`。
每层都把累积色舍到定点格点，存下 `Ĉ_i = C_i + e_i`，于是

```
e_0 = 0
e_i = (1−α_i)·e_{i−1} + δ_i           δ_i 为第 i 层舍入误差
e_N = Σ_{i=1..N} w_i·δ_i              w_i = ∏_{j=i+1..N}(1−α_j),  w_N = 1
```

后层按 (1−α) 衰减前层误差；顶层不衰减。若 |δ_i| ≤ ε_i，则
`|e_N| ≤ Σ w_i·ε_i ≤ 一档`，反解就在这条不等式下分配每层 ε_i。

## 反解每层最大误差

要求 `Σ w_i·ε_i = 一档`。把预算按层数等额切成终值份额（每层占 B/N），
再按该层衰减把它换回存储误差：

```
ε_i* = B / (N · w_i)          B = 一档 = 1.0
```

被上面多层盖住的层 w_i 小、误差被大幅衰减，额度可以很粗；顶层 w_N=1，额度最紧。
把 ε_i* 兑现成定点格式时，从阶梯里挑误差不超过 ε_i* 且格距最粗的一档（就近/截断 × 保护位）。
原来的实现是每层 `uint8(255*x)` 截断并把结果写回 8 位缓冲——这正是粒度为整档、误差 ≤ 1 档的“等分”特例。

## 界的最后一层核对

- **5 层**：闭式界 `Σ w_i·ε_i = 0.7140`；按最坏情况递推到第 5 层 `PrefixBound(·,5) = 0.7140`；两层算法差 `0.00e+00`。
  中间各层累积上界：0.5000、0.8500、0.8450、0.8415、0.7140。
  顶层 w_N=1.0000（必为 1），该层贡献 w_N·ε_N=0.1250；实测总偏差 0.0890 档。
  `0.7140 ≤ 一档 = 1.0`：不超一档。

- **10 层**：闭式界 `Σ w_i·ε_i = 0.6802`；按最坏情况递推到第 10 层 `PrefixBound(·,10) = 0.6802`；两层算法差 `1.11e-16`。
  中间各层累积上界：1.0000、1.7000、2.1900、2.0330、1.9231、1.5962、1.3673、1.0821、0.8825、0.6802。
  顶层 w_N=1.0000（必为 1），该层贡献 w_N·ε_N=0.0625；实测总偏差 0.0325 档。
  `0.6802 ≤ 一档 = 1.0`：不超一档。

## 与等分误差方案对比

等分方案每层都用同一个格式。它的保证界是 `ε·Σ w_i`——把每层同样的误差都乘上各自的衰减再相加。
注意：实际跑出来的那一组 δ_i 有正有负、相位相互抵消，单次实测偏差并不可靠地分出优劣；
**方案的可比数字是保证界**，它对任何颜色组合都成立。

| 层数 | 方案 | 保证界（档） | 分配界（档） | 差值（等分−分配，档） |
|---:|---:|---:|---:|---:|
| 5 | 等分·就近 8 位 | 1.3865 | 0.7140 | **+0.6725** |
| 5 | 等分·截断 8 位（原实现语义） | 2.7731 | 0.7140 | **+2.0590** |
| 10 | 等分·就近 8 位 | 1.6196 | 0.6802 | **+0.9393** |
| 10 | 等分·截断 8 位（原实现语义） | 3.2392 | 0.6802 | **+2.5589** |

同样层数下等分比反解多出的保证界：**5 层 +2.0590 档，10 层 +2.5589 档**（截断 8 位口径；就近 8 位口径为 +0.6725 与 +0.9393 档）。

## 用的是哪套缓冲

本包把“层”建模成 `(color, alpha)` 的 over 递推；渲染器还没有图层缓冲，
`raster.Image.Pix` 仍是每像素 `uint8`、每层 `Fill` 整块覆写（`shading.Apply` 也只认 0/非 0）。
因此这里的反解方案要落地，像素缓冲需要从 `uint8` 改为按分配表定的定点格式
（`Scheme{Mode, Guard}`），或至少引入一个每像素浮点/定点的累积缓冲，最后一次性舍到 8 位。
`Scheme` 的 `Quantum()`、`Err()` 已经按格式给出口径，落地时逐层按 `Plan` 返回的格式舍入即可。
